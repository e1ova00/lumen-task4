# QA-отчёт — LUMEN STUDIO

Дата: 10 ноября 2026. Новая реализация по двум одинаковым документам: исходный сайт для аудита не был предоставлен.

## Выполненные проверки

**16 автоматических тестов пройдены, 0 ошибок.** Команда: `node --test --test-isolation=none --test-reporter=spec tests/*.test.mjs`.

- Все восемь студий: точные координаты, площадь, тариф, вместимость, единый неизменяемый источник данных, оборудование.
- Восемь SVG-сцен и уникальные id градиентов/фильтров, отсутствие фотографий.
- Валидные и невозможные даты, високосный год, пустые значения, прошедшая дата/время, ограничение горизонта, часы открытия/закрытия, дробные часы и гости, нулевая/превышенная вместимость.
- Все типы пересечения интервалов, совпадение границ, соседние интервалы, другая дата и другая студия.
- Для каждой студии: правильная сумма, создание и чтение сохранения, отмена, освобождение времени и повторная бронь.
- Восемь одновременных повторных отправок создают одну запись. Отказ валидации не добавляет запись.
- Повреждённый JSON, неверная схема, дублированные id, резервная копия, запрет доступа и переполнение хранилища; отсутствие ложного сообщения об успешном сохранении. Повторная отмена идемпотентна.
- Совместные фильтры цены/вместимости, сортировка, пустой результат, сброс значений фильтра; исходный массив не меняется.
- Модуль карты с тестовой реализацией Leaflet: те же отфильтрованные точки, фиксированные координаты, выбранное/занятое состояние, обработчик выбора метки, запрет выбора занятой, фокус метки, fitBounds, удаление старых меток и fallback при недоступной библиотеке.

Статическая проверка `python3 tests/static_check.py` пройдена: локальные ресурсы, импорты ES modules, уникальные HTML id, язык `ru`, видимое демо-уведомление, SVG favicon, отсутствие растровых иллюстраций, наличие адаптивных правил, фокуса и reduced-motion. Все JavaScript-файлы проходят `node --check`. Пути относительные; маршруты используют hash, поддерживается размещение в подкаталоге GitHub Pages. Подготовлен workflow Pages без сборки.

## Найденные и исправленные проблемы

1. После исключения внутри синхронного callback Web Locks тестовая очередь могла зависнуть. Callback переведён в async; ошибки освобождают блокировку, последующие операции проходят.
2. Получение `localStorage` в аргументе по умолчанию могло выбросить ошибку раньше её обработки. Доступ перенесён внутрь `try`; отказ хранилища не ломает интерфейс.
3. Некорректное время фильтра могло визуально пометить карту как занятую при другом статусе списка. Добавлена общая проверка интервала и явное состояние «Проверьте время»; выбор блокируется до исправления.
4. При повреждённых сохранениях теперь проверяется схема и сохраняется исходное значение в `.backup` перед восстановлением. Ошибка записи не выдаётся за успешную бронь.

## Что не было проверено в браузере

В управляемом окружении отсутствовал предусмотренный навыком Sites инструмент `cua_repl.js`; навык требует в этом случае пропустить browser QA. Сквозные клики, фактическая загрузка CDN и OSM-тайлов, реальная синхронизация карты/списка через DOM, перезагрузка страницы с localStorage, hash history, экранный диктор, Tab/Shift+Tab, touch-жесты, визуальное качество на desktop/tablet/mobile и отсутствие overflow **не подтверждены браузерным прогоном**. Тест карты использует заглушку API, а тест сохранений — in-memory Storage; это не замена интеграционному тесту браузера. Адаптивность и доступность реализованы и проверены по исходникам.

Ручная приёмка перед сдачей: открыть сайт при 360/768/1440 px; выбрать каждую студию на карте и в списке; проверить фильтры/сброс/пустой результат; оформить бронь, перезагрузить страницу, проверить занятую метку, отменить и забронировать снова; повторить с клавиатуры и при отключённом CDN.

## Оставшиеся ограничения

- Учебное локальное хранилище, без общей базы, аккаунтов и платежей. Данные не синхронизируются между устройствами и доменами.
- В браузерах без Web Locks возможны гонки между вкладками. Поддерживаются современные браузеры; часы рассчитываются в часовом поясе браузера.
- Карта и шрифты зависят от внешних сервисов. При отказе предусмотрены список и системные шрифты.
- Публикация в GitHub пользователя не выполнялась. Подготовлены файлы и workflow для GitHub Pages.
